# Provider input caching

`ProviderGateway` (also exported as `OpenAiGateway`) applies cache controls in the shared Rust model boundary. `ModelRequest.cache` is optional and omitted from legacy serialized requests. `CacheIdentity::new` hashes length-delimited principal, role and scope values; provider keys contain no literal identity. The host supplies layer boundaries and the stable prefix hash. Changing model or role configuration creates a distinct gateway identity. Replay restores the recorded context policy through `context_policy_override`, exact per-step cache metadata through `request_cache_override` and recorded usage for calibration, without new traffic. The engine validates the policy before use.

| Adapter | Request contract | Reported accounting |
|---|---|---|
| Anthropic Messages | At most four ordered content-block `cache_control` marks, `ephemeral` with `5m` or `1h`. Only initial L0–L3 form the stable system field; L4 and L5 retain their conversation position even before the first activity turn. Full tool definitions remain present when `tool_choice` becomes `none`. | Inclusive input adds uncached, cache-read and cache-creation tokens. Separate read, creation and 5m/1h creation counts are retained. |
| OpenAI Chat Completions | Stable `prompt_cache_key`; sorted full tool catalogue and `tool_choice: auto/none`. No Anthropic TTL or speculative cache options are sent. Retention and minimums depend on the actual model/API contract. | Input includes cached tokens; `cached_tokens` is a subset. Missing cache-write counts remain unknown. |
| Gemini generateContent | Implicit caching: preserve the common prefix without adding cache parameters. Late runtime instructions retain their order in explicit user frames because this API has only user/model conversation roles. | Inclusive prompt count and reported cached subset; response plus thinking tokens form output. |
| Compatible economical/local endpoints | Preserve the same prefix and tool catalogue, without injecting provider-specific cache flags. A server must support and enable reuse. | DeepSeek hit counts are reads; miss counts are uncached input, not cache writes. Qwen-compatible cached-token counters are recognized. |

Gemini response parts, including thought signatures and native call identities, are durable opaque `Message.provider_state` data. Replay checks that visible text and calls still match before returning the original parts. Anthropic thinking blocks and signatures receive the same preservation. These adapters handle text and function calls; they do not claim support for every native multimedia part. Model-specific unsupported sampling/thinking controls fail explicitly. `GatewayConfig.native_system_updates` lets the host attest Anthropic native support; without an override a conservative list of documented models is used. Older/unknown models or invalid native placements use user frames preserving literal text and position. Opaque state never becomes instruction text in the compatible textual protocol.

`complete_fanout` uses `complete_cache_warm_observed` to start the first actual Anthropic sibling once, waits for its first useful streamed delta, then admits followers within the concurrency bound. A failed leader before that delta leaves followers undispatched. Dropping the future aborts active local requests. Successful empty output releases followers after completion and reports that distinction. Ordinary public worker streaming methods still deliver only the complete response; the internal warming stream admits deltas without changing that contract. This helper does not create or manage subagent tasks.

`CacheObservation` compares prefix eligibility with provider-reported counts. Equal hashes do not establish a hit; absent counters stay `None`. Accounting rejects inconsistent subsets. Tests use local HTTP/SSE fixtures, including deliberate misses despite an unchanged prefix, real incremental release, failure and cancellation. They establish adapter behavior, not production cache-hit rates or savings.

Verification: `cargo test -p excalibur-models --test cache` and `cargo test -p excalibur-models -p excalibur-providers`.

Official contracts checked on 2026-10-29:

- [Anthropic caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching), [system updates](https://platform.claude.com/docs/en/build-with-claude/mid-conversation-system-messages), [thinking](https://platform.claude.com/docs/en/build-with-claude/extended-thinking).
- [OpenAI caching](https://developers.openai.com/api/docs/guides/prompt-caching) and [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
- [Gemini caching](https://ai.google.dev/gemini-api/docs/caching), [generateContent parts and usage](https://ai.google.dev/api/generate-content). Gemini 4 Argon/newer request reuse has the documented 2,050-token increment condition; the adapter does not pad requests to satisfy it.
- [DeepSeek prefix caching](https://api-docs.deepseek.com/guides/kv_cache/), [Qwen context caching](https://help.aliyun.com/en/model-studio/context-cache), [vLLM prefix caching](https://docs.vllm.ai/en/latest/features/automatic_prefix_caching/).

- [GLM automatic caching](https://docs.z.ai/guides/capabilities/cache), [Kimi read/write counters](https://www.kimi.ai/academy/best-practices-for-context-caching), [llama.cpp cache](https://github.com/ggml-org/llama.cpp/blob/master/tools/server/README.md), [Ollama partial compatibility](https://docs.ollama.com/api/openai-compatibility). Counters or hits not reported by a server remain unknown.

The current optional live inference profile is `gpt-6-luna` with `GatewayConfig.reasoning_effort = Some("low".into())`. Synthetic regression tests remain offline. For a Chat Completions inference probe, omit function tools: [the Luna contract](https://developers.openai.com/api/docs/models/gpt-6-luna) restricts Chat Completions function calling to effort `none`; low-effort function calling requires Responses, which this model gateway does not claim to implement. Embeddings (`text-embedding-3-small`) and Decisions API are separate capabilities and are not invoked by context/cache preparation. External test credentials are supplied privately by the host, never serialized into context or replay.
