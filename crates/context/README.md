# Shared context sessions

`compile(&ContextInput)` retains its original deterministic assembly contract. `ContextSession` adds a serializable view over immutable messages and durable history references; it does not call a model, read files or obtain a clock. The host supplies explicit time, current structured facts and any optional extractor result. Small sessions produce the same request bytes as the legacy compiler.

Use `ContextSession::new(base, policy)`, bind initial messages to their real seed with `bind_initial_history`, append confirmed messages with stable IDs, and supply real blob references for observations. `append` rejects changed content under an existing ID. `update_layer` accepts monotonic L2/L3 revisions; `update_layer_changed` assigns the next revision for a changed snapshot. Both append an L4 update and preserve the frozen original prefix. `set_pins` replaces the complete pin set. `inspect_prefix` and `detect_drift` classify L0/L1 changes as defects. Tool definitions remain sorted by the existing compiler.

Before preparing, the host can request `summary_request_with_volatile` using the exact volatile input. Pass a strict `IncrementalSummary` addition as `SummaryOutcome::Added`, or use `Unavailable`/`NotRequested` for deterministic fallback. `prepare` returns the compiled request and a receipt, and commits its in-memory projection only on success. Persist the session and receipt before model dispatch. The host adapter owns database transactions, blob verification, secrets redaction and model usage accounting.

Masking starts above 24,000 estimated observation tokens and removes eligible oldest observations until the estimate is at most 12,000. Estimates include the 10% margin. The latest ten results, pinned results and errors among the latest twenty observations are protected. An expired explicit TTL can advance the batch. Between batches the view remains unchanged. Markers contain SHA-256, line count, history provenance and a real `get_tool_output` hash argument. A missing durable archive is an error; an untrusted `full_output_blob` claim inside message text does not establish provenance. Original messages stay available through `history_lookup`/`history_search` and the durable references. No source history is deleted.

Compaction triggers at `min(compaction_cap, floor(0.85 * model_window) - output_reserve)`. It tries masking first, then builds authoritative structured state, adds only the newly discarded segment to the existing non-authoritative summary, and mechanically repairs open identifiers. Invalid, stale or unavailable summaries fall back to structured facts and the recent window. The last 20,000 activity tokens are retained without splitting a tool interaction; pins and recent errors can retain additional whole groups. Receipts record hashes, discarded ranges, source references, retained IDs and target overflow. A single indivisible group can exceed its target. Protected content that cannot fit the model input window produces a bounded-context error instead of silent truncation.

For conversations, literal turns target 12,000 tokens; condensation happens above 24,000 or after TTL expiry when above the target, rather than every turn. Durable instructions come from explicit literal registry records, are appended as versioned changes, and are rendered literally into L2/L3 at compaction. They do not depend on extractor output.

The managed L4 view uses the configured model window rather than the legacy default 16K L4 budget. L0–L3 and L5 retain explicit budgets, checked with the selected estimator and margin. A host must configure the model's actual window and cache TTL; defaults are operating policy, not verified provider limits.

`TokenCounter` uses bundled local BPE vocabularies for known OpenAI encodings and ordinary text encoding for untrusted special-token strings. Unknown models use a character estimate. Provider-reported total input usage, including cache reads/writes, calibrates an integer EWMA per model; estimated or absent usage cannot calibrate it. Local text tokenization is exact for its encoding; request framing and nonlocal estimates remain estimates. The 10% margin and synthetic convergence tests do not guarantee every provider tokenizer or billing total.

Dependency and encoding evidence: [tiktoken-rs 0.12.1](https://crates.io/crates/tiktoken-rs/0.12.1), [maintainer API documentation](https://docs.rs/tiktoken-rs/0.12.1/tiktoken_rs/), and [OpenAI's encoding mapping](https://github.com/openai/tiktoken/blob/main/tiktoken/model.py). Tokenizer assets are bundled; runtime tokenization makes no network calls.

Run `cargo test -p excalibur-context` and `cargo clippy -p excalibur-context --all-targets -- -D warnings`. Backend tests cover masking, archive recovery, immutable IDs, tool-pair preservation, structured and incremental compaction, summary failure, literal instructions, conversation boundaries, token calibration and identical bytes across restarts and separate processes. The two ignored helper cases are invoked explicitly by their parent subprocess tests. These tests do not measure a live provider's cache hit rate or savings.
