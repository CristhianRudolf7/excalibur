# Progress updates

## Structure

1. **Done**: completed items with their evidence in one line each.
2. **Remaining**: what is left and the current estimate.
3. **Needed from you**: decisions, approvals or inputs, each phrased so it can be answered quickly.
4. **Next update**: when or at which event you will report again.

## Rules

- Plain language; no internal identifiers unless the user uses them.
- Report problems and failed checks as clearly as successes.
- Do not claim progress that has no evidence.
