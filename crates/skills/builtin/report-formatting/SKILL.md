# Report formatting

## Steps

1. Look for an existing template or a previous deliverable of the same kind and reuse its structure.
2. Otherwise use: summary first (the answer or outcome), then details, then evidence and open items.
3. Match the user's preferred format (Markdown, document, spreadsheet, slides) and length.
4. Put numbers with units and sources; separate facts from estimates and from recommendations.
5. End with what the user needs to do, if anything.

Never pad a report to look complete; omit empty sections.
