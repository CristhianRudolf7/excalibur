# Roadmap

[Español](ROADMAP.es.md)

The following items are plans, not completed features or fixed release commitments.

1. Establish a coding-agent foundation with a CLI, one model provider and a tool execution loop.
2. Develop task planning, project context, memory, skills and subagent coordination; evaluate the agent with representative tasks.
3. Add a web interface and expand capabilities and provider support.
4. Explore a store for tools and automation workflows, including catalog, installation and publishing.

Scope and sequencing can change as the project evolves.

## Platform scope

Current implementation and verification scope is Linux. Windows, macOS and mobile profiles keep their contracts (including capabilities, workflows and MCP); support planned for a later phase.
